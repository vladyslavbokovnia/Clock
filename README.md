# Clock wallpaper

Мобильная заставка с механическими декоративными индикаторами поверх исходного изображения.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 4173
```

## Индикаторы

- Центральные часовая и минутная стрелки обновляются каждую секунду.
- Верхний круг показывает заряд батареи, если браузер поддерживает Battery Status API; иначе используется безопасное значение 75%.
- Левый круг показывает текущий день недели, воскресенье находится в верхней точке.
- Нижний круг показывает прогресс текущего года по месяцам, стрелка указывает на текущий месяц.
- Фон — `assets/clock-background.png`, исходное пользовательское изображение.
