# Clock wallpaper

Мобильная заставка с механическими декоративными стрелками поверх исходного изображения.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 4173
```

## Индикаторы

- Центральные часовая и минутная стрелки обновляются каждую секунду.
- Верхняя декоративная стрелка показывает заряд батареи, если браузер поддерживает Battery Status API; иначе используется безопасное значение 75%.
- Левая декоративная стрелка показывает текущий день недели, воскресенье находится в верхней точке.
- Нижняя декоративная стрелка показывает текущий месяц года.
- Дополнительные SVG-прогресс-бары поверх фона отключены: состояние читается по стрелкам.
- Фон — `assets/clock-background.png`, исходное пользовательское изображение.
