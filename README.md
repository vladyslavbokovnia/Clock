# Clock wallpaper

Мобильная заставка с механическими декоративными стрелками поверх исходного изображения.

## Запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня проекта, например:

```bash
python3 -m http.server 4173
```

## Индикаторы

- Центральные часовая и минутная стрелки обновляются каждую секунду.
- Верхняя декоративная стрелка показывает заряд батареи, если браузер поддерживает Battery Status API; иначе используется безопасное значение 75%.
- Левая декоративная стрелка показывает текущий день недели, воскресенье находится в верхней точке.
- Нижняя декоративная стрелка показывает текущий месяц года.
- Дополнительные круги, шкалы, подписи и SVG-прогресс-бары поверх фона отключены: используются только стрелки, совмещённые с циферблатами исходного изображения.

## Установка как мини-приложения

Откройте страницу через HTTPS в Chrome или Edge, нажмите меню браузера и выберите **«Установить приложение»** или **«Добавить на главный экран»**. После установки `Clock` запускается отдельным полноэкранным окном без адресной строки. Для iPhone откройте страницу в Safari, нажмите **Поделиться → На экран «Домой»**.

Файл `index.html` теперь содержит встроенную копию фонового изображения. Его можно скачать отдельно и открыть напрямую — папка `assets` для отображения фона больше не обязательна.
- Фон — `assets/clock-background.png`, исходное пользовательское изображение.

На опубликованной HTTPS-странице GitHub Pages установка PWA доступна в Chrome/Edge. Если браузер не показывает пункт установки, используйте кнопку `⛶` в правом верхнем углу — она включает настоящий fullscreen по нажатию.

## Android APK для Bigme HiBreak

В корне проекта находится `ClockWallpaper-debug.apk`. Это нативное приложение для Android 11 без браузера. После установки откройте приложение один раз и включите разрешение на показ поверх других приложений, если Bigme его запросит. Служба запускается автоматически после перезагрузки.

По умолчанию приложение будит экран на 1 секунду каждые 5 минут. Оно также реагирует на переворот телефона в портретное положение вверх ногами. В настройках можно отключить пробуждение по перевороту, блокировать включение при датчике приближения или когда телефон лежит экраном вниз, а также отключить автозапуск после перезагрузки.
