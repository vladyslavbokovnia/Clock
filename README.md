# Clock Wallpaper

Android-приложение для Bigme HiBreak на Android 11: механическая заставка, рабочие стрелки времени, батареи и календаря, пробуждение по точному пятиминутному таймеру, переворот, overlay и настройки фонового режима.

## Структура

Весь исходный проект находится в каталоге `android-app`. Старая веб-версия и собранные APK из репозитория удалены.

## Сборка локально

```bash
cd android-app
chmod +x gradlew
./gradlew clean assembleDebug
```

Готовый файл появится здесь:

```text
android-app/app/build/outputs/apk/debug/app-debug.apk
```

## Сборка через GitHub Actions

Workflow находится в `.github/workflows/build-apk.yml` и запускается автоматически при push или pull request в `main`. Его также можно запустить вручную через **Actions → Build Clock APK → Run workflow**.

После завершения сборки APK доступен в разделе **Artifacts** текущего запуска под именем `ClockWallpaper-debug`.

## Основные функции

Приложение поддерживает обновление заставки каждые пять минут при выключенном экране, запуск заставки при перевороте при включённом экране, виброотклик при перевороте, крупные календарные метки, индикатор батареи и зарядки, тёмные настройки, accessibility overlay, отдельное разрешение overlay и ежедневный будильник для возобновления активного медиаплеера.
